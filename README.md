# Kord

A lightweight, glass-styled window for Discord on Windows: Discord's own web app in a small frameless window with macOS-style buttons.

**Download:** grab `Kord.exe` from the [latest release](https://github.com/bitmyswag/kord/releases/latest), put it in a folder you'll keep, and open it. Sign in on Discord's own login page.

Updates are your choice: Kord > Updates shows new versions, and Version history lets you switch back to an older one.

This repository only holds the downloads.
